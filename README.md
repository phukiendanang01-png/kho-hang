# Hậu Store - Quản lý kho hàng

**App:** https://phukiendanang01-png.github.io/kho-hang/

App quản lý kho hàng 1 file, chạy trên Android / iOS / macOS.

Tính năng: nhập/xuất hàng (tự trừ kho), tồn kho + tìm kiếm IMEI,
**báo cáo lợi nhuận theo kỳ (7 ngày / tháng này / tháng trước)**,
xuất & đọc file Excel, đồng bộ Google Sheet.

- `index.html` — app (mở bằng trình duyệt)
- `google-apps-script.gs` — dán vào Google Sheet (Extensions → Apps Script) để bật đồng bộ online
- `HUONG-DAN.txt` — hướng dẫn cài đặt & dùng
